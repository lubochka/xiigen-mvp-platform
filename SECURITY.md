# Security Policy

## Initial contact

To report a suspected vulnerability, open a minimal request in [this repository's issues](https://github.com/lubochka/xiigen-platform-dot-net-angular/issues) asking the maintainer to arrange a private reporting channel. A suitable title is "Request for a private security contact".

Include no vulnerability details, reproduction steps, credentials, affected private tenant information or sensitive logs in that public request. Wait until a private channel has been agreed before sending the report.

## Private report

Once the channel is agreed, provide the affected revision and component, a minimal synthetic reproduction, expected and observed behavior, and the impact you can demonstrate. Remove secrets and personal data from attachments. Do not probe systems or accounts you are not authorized to assess.

If you find a credential in source or an artifact, report its location and type without copying its value. Removing a value from a file does not revoke it; the owner must handle revocation or rotation.

Please allow maintainers to assess the report before publishing vulnerability details.
