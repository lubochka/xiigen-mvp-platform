# Corporate Install Evidence Contract — Enterprise v3.2

Corporate install/import cannot pass unless evidence proves:

1. manifest verified;
2. signature verified;
3. hash/provenance verified;
4. no-secrets scan accepted;
5. trainable unit locator imported;
6. checkpoint references resolved;
7. server/client/data health checks completed;
8. Visual Studio and VS Code locator can find imported units;
9. rollback path exists;
10. evidence report is persisted.

Missing runtime metric values are UNKNOWN, not PASS.
