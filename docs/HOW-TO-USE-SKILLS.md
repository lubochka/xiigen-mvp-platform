## Binding Order

For XIIGen Enterprise adaptation, skills are subordinate to the beacon:

1. Read `docs/plans/enterprise-adaptation/v3.3/XIIGEN-ENTERPRISE-ADAPTATION-BEACON-PROMPT-v1.md`.
2. Read `docs/plans/enterprise-adaptation/v3.3/XIIGEN-ENTERPRISE-ADAPTATION-STATE-v3.3.json`.
3. Read `docs/plans/enterprise-adaptation/v3.3/XIIGEN-ENTERPRISE-ADAPTATION-COMPLETION-MATRIX-v3.3.md`.
4. Read the active session file.
5. Only then apply the relevant architecture, execution, review, code-quality, AWS, plugin, visual-evidence, or legal-site skills.

No skill may authorize a final report, soften a stop gate, replace AWS runtime evidence with localhost evidence, replace interactive IDE plugin evidence with a contract harness, or let executor self-finish.
