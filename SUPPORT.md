# Support

Use [this repository's issues](https://github.com/lubochka/xiigen-platform-dot-net-angular/issues) for usage questions, reproducible bugs, documentation corrections and feature proposals. Include the revision, affected component or flow, relevant environment and a small synthetic example. Search existing issues first when practical.

Use the available bug, documentation or feature forms when they fit. For other requests, open a regular issue. Remove credentials, personal information and private tenant data from logs and screenshots.

For a suspected vulnerability, follow [SECURITY.md](SECURITY.md): request a private channel without posting the vulnerability details. For a sensitive conduct report, likewise request a private contact channel without naming people or describing private events publicly; provide details only after that channel is agreed.

See the [README](README.md), [FAQ](docs/FAQ.md) and [contributor guide](CONTRIBUTING.md) for project guidance. Support is coordinated through issues.
